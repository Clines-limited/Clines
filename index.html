How do I install Clines on Windows?
Choose Windows in the download window, open the downloaded Clines-Setup.exe, and follow the installer. Windows may show its usual security prompt for apps downloaded from the internet.
How do I install the Android APK?
Choose Android APK, download Clines.apk, then open it and approve installation when Android asks. Depending on your settings, you may need to allow your browser or file manager to install apps. Only install APKs you trust.
How do updates work?
Clines checks for required updates in supported app builds. Windows downloads the update and restarts to install it; Android downloads the APK and opens Android’s installer for approval. Successful in-place Android upgrades require a consistent app signing key.
What changed in v1.0.6?
Version 1.0.6 is a UI initialization hotfix. It restores the Blocked users sidebar button and prevents that event hookup from interrupting the rest of the app’s button setup. See release details.
Can I use Clines in a browser?
Yes. You can open the Clines web app in a supported browser. Messaging and media sync require an internet connection.
